# 압축 뒤에도 프로젝트 지침 유지하기

[English](PROJECT_GUIDANCE.md) · [문서 목록](README.ko.md)

플러그인은 SessionStart 훅이 실행될 때 프로젝트 지침 파일을 읽습니다.
읽은 본문을 다음 모델 문맥에 직접 넣습니다.
같은 세션을 재개하거나 문맥을 압축한 뒤에도 이 동작을 수행합니다.
체인 연결이나 새 세션은 필요하지 않습니다.

## 사용

1. [업데이트 절차](OPERATIONS.ko.md)에 따라 플러그인을 갱신하세요.
2. Codex `/hooks`에서 훅을 검토하세요.
3. 사용할 훅을 신뢰하도록 설정하세요.
4. 프로젝트 지침을 `AGENTS.md`에 작성하세요.
5. 해당 프로젝트에서 작업을 계속하세요.

플러그인에는 파일을 읽는 기능이 들어 있습니다.
개발자의 개인 프로젝트 지침은 포함하지 않습니다.
플러그인은 사용자의 지침 파일을 만들거나 바꾸지 않습니다.
본문을 메시지 저널이나 체이닝 체크포인트에 복사하지 않습니다.
Codex는 주입한 본문을 대화 기록과 모델 요청에 포함할 수 있습니다.
주의: 지침 파일에 비밀 정보를 넣지 마세요.

## 파일 선택

Git worktree에서는 해당 worktree의 루트부터 탐색합니다.
훅의 현재 작업 폴더까지 이어지는 각 폴더를 확인합니다.
다른 worktree나 공통 Git 폴더의 지침을 읽지 않습니다.
Git 저장소 밖에서는 현재 폴더만 확인합니다.

각 폴더에서는 내용이 있는 `AGENTS.override.md`를 먼저 선택합니다.
이 파일이 없거나 비어 있으면 같은 폴더의 `AGENTS.md`를 선택합니다.
override 파일을 읽을 수 없거나 내용 형식이 잘못됐으면 오류를 표시합니다.
이 오류를 숨기고 다른 파일을 선택하지 않습니다.
문맥에는 루트에서 현재 폴더 순서로 선택한 파일을 넣습니다.
현재 폴더에 더 가까운 지침은 해당 범위에 적용합니다.

이 기능은 전역 Codex 지침이나 사용자가 정한 다른 파일 이름을 탐색하지 않습니다.
지침에서 참조하는 파일도 자동으로 읽지 않습니다.
Codex 자체의 지침 탐색은 그대로 동작합니다.
플러그인은 SessionStart에서 본문을 추가로 전달하며 Codex가 넣은 본문을 지우지 않습니다.

## 실행 시점과 한도

SessionStart에는 시작, 재개, 초기화, 압축 이벤트가 포함됩니다.
플러그인은 각 이벤트에서 파일을 새로 읽습니다.
본문을 담는 영속 캐시는 만들지 않습니다.
일반 UserPromptSubmit 이벤트에서는 본문을 추가하지 않습니다.
대화 중 파일만 바뀌면 다음 SessionStart에서 변경 내용을 읽습니다.
하위 에이전트는 부모의 훅을 통해 이 기능을 실행하지 않습니다.

선택한 본문의 합계 한도는 32 KiB입니다.
일반 파일과 올바른 UTF-8만 허용합니다.
파일 링크와 현재 프로젝트 경계를 벗어나는 경로는 거부합니다.
읽기에 실패하거나 합계 한도를 넘으면 선택한 본문 전체를 생략합니다.
지시를 중간에서 자르지 않고 실패 이유를 표시합니다.
이 정책은 Codex 자체의 지침 크기 제한 처리와 다릅니다.
읽기에는 시간 한도가 있으며 시간 초과 뒤 재시도하지 않습니다.
읽기 실패가 메시지 전달이나 인계 복원을 끄지는 않습니다.
지침 파일이 없는 상태는 정상입니다.

프로젝트 지침은 새 승인을 주거나 세션 권한을 바꾸지 않습니다.
동료 메시지와 저장된 인계는 별도의 신뢰하지 않는 자료로 유지합니다.
본문 전달은 모델의 지침 준수를 입증하지 않습니다.

## 프로젝트 훅의 중복 주입 방지

기존 프로젝트 훅이 같은 파일의 본문을 넣고 있을 수 있습니다.
본문을 넣는 훅은 하나만 사용하세요.
작업 추적 등 다른 프로젝트 훅 기능은 따로 유지할 수 있습니다.
플러그인은 다른 훅을 끄거나 수정하지 않습니다.

이 읽기 기능을 끄려면 플러그인 훅 프로세스의 환경에 `CROSS_SESSION_PROJECT_GUIDANCE=0`을 설정하세요.
다른 플러그인 기능은 계속 동작합니다.
공유 데몬에서는 새 CLI 프로세스에만 설정한 변수가 훅에 도달하지 않을 수 있습니다.
실제로 훅 명령을 실행하는 호스트나 실행 도우미에 환경을 설정해야 합니다.
플러그인은 이 설정을 적용하려고 데몬을 재시작하거나 훅 신뢰를 바꾸지 않습니다.
