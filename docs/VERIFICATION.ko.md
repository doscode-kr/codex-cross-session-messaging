### 호스트 Stop과 Interrupt 검사

격리된 Windows 검사는 Codex CLI 0.161.0과 로컬 모형 모델을 사용했습니다.

테스트는 설치된 MCP 도구의 조회를 확인합니다.
테스트는 작업 중인 세션과 대기 중인 세션의 동료 메시지 본문이 모델 요청에 포함되는지 확인합니다.
테스트는 실제 모델 API를 호출하지 않습니다.

PowerShell:

```powershell
$previousIntegrationSetting = $env:CROSS_SESSION_REAL_CODEX_TEST
try {
    $env:CROSS_SESSION_REAL_CODEX_TEST = '1'
    npm test
} finally {
    if ($null -eq $previousIntegrationSetting) {
        Remove-Item Env:CROSS_SESSION_REAL_CODEX_TEST -ErrorAction SilentlyContinue
    } else {
        $env:CROSS_SESSION_REAL_CODEX_TEST = $previousIntegrationSetting
    }
}
```

macOS 셸:

```sh
CROSS_SESSION_REAL_CODEX_TEST=1 npm test
```

이 명령은 다음 실행을 위한 안내입니다.
기록된 Windows 결과는 위에 있습니다.
위의 CI 기준 결과는 명시한 commit의 macOS 실행을 기록합니다.

## 배포 후보 문서 검사

2026-10-08의 문서 작업은 Windows에서 `npm run check`와 `git diff --check`를 실행했습니다.
두 검사는 통과했습니다.
독립 상대 링크 검사는 Markdown 파일 15개의 로컬 링크 38개를 확인했습니다.
YAML 검사는 CI 작업 흐름과 오류 보고 양식을 읽었습니다.
루트 라이선스와 플러그인 라이선스 사본은 일치했습니다.
직접 실행한 `node scripts/install.mjs --dry-run`은 통과했습니다.
해당 명령은 예정된 의존성 설치와 마켓플레이스 등록과 플러그인 설치 명령을 출력했습니다.
해당 명령은 출력한 작업을 실행하지 않았습니다.

이 환경의 PowerShell에서 `npm run install:global -- --dry-run`은 설치 스크립트에 옵션을 전달하지 않았습니다.
해당 실행은 로컬 의존성을 설치했습니다.
이후 마켓플레이스 등록은 원본 충돌로 실패했습니다.
해당 실행은 플러그인 설치를 수행하지 않았습니다.
사용자는 설치 옵션을 지정할 때 직접 Node.js 명령을 사용합니다.

## 한계

- CI 결과는 명시한 commit과 시험한 환경 조합에만 적용됩니다.

- 격리된 테스트는 여러 대화형 터미널에서 훅을 신뢰한 상태의 사용을 검증하지 않습니다.
- 목록 조회의 시간 조건 테스트는 8.3 실행 데이터 경로 별칭을 감지한 후 생략했습니다.
