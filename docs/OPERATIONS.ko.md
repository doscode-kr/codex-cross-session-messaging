# 업데이트와 진단

[English](OPERATIONS.md)

## 같은 원본 폴더에서 업데이트

1. 사용자는 현재 릴리스 태그나 commit을 기록합니다.
2. 사용자는 등록된 원본 폴더에서 새 릴리스를 받습니다.
3. 사용자는 [변경 기록](../CHANGELOG.ko.md)을 읽습니다.
4. 사용자는 신청한 원래 세션에서 남은 대기 알림을 취소합니다.
5. 사용자는 기존 플러그인을 읽은 세션을 닫습니다.
6. 사용자는 외부 셸에서 메시지 브로커를 종료합니다.

   ```text
   node plugins/cross-session/src/cli.mjs broker-stop
   ```

7. 사용자는 설치 명령을 확인합니다.

   ```text
   node scripts/install.mjs --dry-run
   ```

8. 사용자는 기존 플러그인 캐시를 삭제합니다.

   ```text
   codex plugin remove cross-session@cross-session-local
   ```

9. 사용자는 새 원본을 설치합니다.

   ```text
   npm run install:global
   ```

10. 사용자는 새 Codex CLI 세션을 엽니다.
11. 사용자는 `/hooks`에서 새 훅을 검토합니다.
12. 사용자는 `npm run doctor`를 실행합니다.

원본 폴더와 설치된 캐시는 별도 위치입니다.
원본 변경만으로 캐시 업데이트를 확인할 수 없습니다.
이 절차는 메시지 데이터를 유지합니다.
설치 스크립트는 운영 데몬을 재시작하지 않습니다.
브로커 종료 후 다음 플러그인 호출은 새 브로커 코드를 읽습니다.
`broker-stop`의 `BROKER_OFFLINE`은 해당 메시지 폴더의 브로커가 실행 중이 아니라는 뜻입니다.
종료 훅이 브로커를 다시 시작할 수 있으므로 사용자는 브로커 종료 전에 플러그인 세션을 닫습니다.

## 원본 폴더 변경

마켓플레이스 이름이 다른 원본에 등록되어 있을 수 있습니다.
이 경우 설치 스크립트는 오류를 반환합니다.

1. 사용자는 `codex plugin list --json`으로 설치 목록을 읽습니다.
2. 사용자는 다른 설치된 플러그인의 `cross-session-local` 사용 여부를 확인합니다.
3. 사용자는 신청한 원래 세션에서 남은 대기 알림을 취소합니다.
4. 사용자는 기존 플러그인을 읽은 세션을 닫습니다.
5. 사용자는 외부 셸에서 `node plugins/cross-session/src/cli.mjs broker-stop`을 실행합니다.
6. 사용자는 `codex plugin remove cross-session@cross-session-local`을 실행합니다.
7. 다른 설치된 플러그인이 사용하지 않으면 사용자는 `codex plugin marketplace remove cross-session-local`을 실행합니다.
8. 사용자는 새 원본 폴더에서 `npm run install:global`을 실행합니다.
9. 사용자는 새 Codex CLI 세션을 엽니다.
10. 사용자는 `/hooks`에서 훅을 검토합니다.

다른 설치된 플러그인이 해당 마켓플레이스를 사용하면 사용자는 2단계 후 이 절차를 중단합니다.
사용자는 해당 등록과 원본을 유지합니다.
기존 등록을 유지하며 새 원본이 필요하면 사용자는 별도 `CODEX_HOME`을 사용합니다.

사용자는 각 명령에 같은 `CODEX_HOME`을 사용합니다.
사용자는 새 설치를 확인할 때까지 기존 원본을 유지합니다.
이전 상태가 필요하면 사용자는 기록한 릴리스를 다시 설치합니다.

## 진단

| 문제 | 확인할 항목 |
|---|---|
| Codex 실행 파일 없음 | `CROSS_SESSION_CODEX_BIN`에 실행 파일 절대 경로를 지정합니다. |
| 공유 데몬 없음 | `--no-daemon` 없이 일반 Codex CLI 세션을 시작합니다. |
| 세션 목록 누락 | 독립 루트 세션이 데몬에 적재되었는지 확인합니다. |
| 이름이나 프로젝트 정보 없음 | 훅 신뢰를 확인합니다. 세션 이름을 등록합니다. |
| 전달 결과 불확실 | 재전송 전에 발신 기록을 읽습니다. |
| 브로커 종료 거부 | 현재 세션의 대기 알림을 취소합니다. |
| 마켓플레이스 원본 충돌 | 위의 원본 폴더 변경 절차를 따릅니다. |

`npm run doctor`는 데몬과 세션 목록을 읽습니다.
출력에는 세션 ID와 프로젝트 경로가 포함될 수 있습니다.
사용자는 출력을 공유하기 전에 개인정보를 제거합니다.

브로커 종료 명령은 `node plugins/cross-session/src/cli.mjs broker-stop`입니다.
이 명령은 Codex 데몬을 종료하지 않습니다.
대기 알림 신청이 남으면 브로커는 종료를 거부합니다.
삭제와 데이터 정리는 [삭제 안내](UNINSTALL.ko.md)를 따릅니다.
